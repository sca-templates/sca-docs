# Tempo

> Distributed tracing backend: stores OpenTelemetry spans so requests can be correlated end-to-end across services.

## Role in the platform

- Receives traces generated by OpenTelemetry SDKs instrumented in every service (wired through `@sca/*` plumbing).
- Latency and error diagnosis across service hops — find the slow or failing hop in one view.
- Trace↔log↔metric correlation inside Grafana next to [[loki]] logs and [[prometheus]] metrics.

## Deployment

- Helm install from `infra-kubernetes`; Grafana datasource provisioned alongside ([[grafana]]).
